# ranger-conv

Un mod pour l'onglet Code de l'appli Claude de bureau (Mac ou Windows), sur la ligne du modèle, sous la saisie :

- **Mieux** réécrit ton brouillon (fautes, clarté) sans l'envoyer.
- **⋯** déplie **Retiens** (Claude retient une consigne), **Vider** (vide la conversation) et **Archiver** (renomme puis archive).
- Aussi en commandes : `/retiens [texte]`, `/vider`, `/archiver`.

## Installer

1. Dans l'appli Claude, onglet Code, ouvre une conversation et colle :

   ```text
   Ajoute le catalogue de plugins GitHub Drayk0/claude-mods, puis installe ranger-conv pour mon utilisateur.
   ```

2. Quitte l'appli complètement (⌘Q sur Mac, clic droit sur l'icône de la barre des tâches > Quitter sur Windows) et rouvre-la.
3. Les boutons et les commandes apparaissent après le premier message d'une **nouvelle** conversation.

## Mettre à jour

```text
Mets à jour le catalogue claude-mods et ses plugins.
```

Puis quitte et rouvre l'appli.
